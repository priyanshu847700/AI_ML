# Goal
- Classify data into categories with multiple algorithms.

# What is classification algorithms-
1. Logistic regression.
2. K-Nearest Neighbours(KNN)
3. Decision Tree.
4. Random Forest Classifier.
5. Naive Bayes
6. SVM (support vector machines)


- Evaluation Metrics:  Accuracy, Precision, Recall, F1-score. Confusion Matrix.
- K-Fold cross validation.



# What is Classification
- A classification algorithm is a type of machine learning algorithm used to predict a  category  or class label for a given input.
" Classification is the process of teaching a machine to answer questions like: "Is this a cat or a dog?" or "Will this customer survive or not."
